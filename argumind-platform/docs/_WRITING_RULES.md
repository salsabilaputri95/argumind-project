## **Aturan umum:**

1. Keluarkan hanya isi file. Tanpa kata pembuka, penutup, atau penjelasan proses.
2. Padat: kalimat pendek, tabel atau daftar alih-alih paragraf, tanpa kata pengisi, tanpa pengulangan. Info yang sudah ada di file lain cukup dirujuk: → docs/X.md#bagian.
3. Konkret dan bisa diuji: tulis nilai eksplisit (hex, px, tipe data, kode status, angka), bukan kata sifat. Gunakan kata perintah WAJIB dan JANGAN. Beri satu contoh minimal per pola.
4. Jangan mengarang nilai, versi, angka, URL, atau sitasi. Jika tidak diketahui, tulis TODO(pertanyaan). Jika terpaksa berasumsi, tulis ASUMSI: di tempatnya.
5. Semua item SPEK wajib terpenuhi. Jika ada yang tidak relevan, tulis satu baris alasannya, jangan dihapus diam-diam.
6. Awali file dengan header tiga baris: Tujuan, Status dan tanggal, Sumber kebenaran untuk apa.
7. Pakai ID dan istilah yang konsisten lintas file (F-01 untuk fitur, RQ1 untuk pertanyaan penelitian, E-01 untuk eksperimen, ADR-01 untuk keputusan).
8. Bahasa isi: Indonesia. Nama field, path, perintah, dan kode: Inggris.
9. Baca hanya file di bagian Baca. Kumpulkan semua informasi yang kurang dalam satu daftar bernomor (maks 10, prioritaskan yang memblokir) dan tunggu jawaban sebelum menulis. Pertanyaan yang tidak memblokir diganti ASUMSI:.
10. Jika melewati batas panjang, pecah ke file terpisah dan rujuk. Akhiri file dengan bagian Pertanyaan terbuka (jika ada).
